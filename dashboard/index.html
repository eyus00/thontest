Why this result matters

Hobby–Rice balances the continuous relaxation.

Hobby–Rice, proved using Borsuk–Ulam, guarantees a continuous ±1 partition balancing selected measures. This computed certificate is numerical; switches may split assets, so it does not guarantee exact balance or optimality for the discrete portfolio.
